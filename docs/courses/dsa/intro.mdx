# DSA

DSA là lộ trình trọng tâm đầu tiên của Visualize Code. Course này sẽ giúp người học hiểu cấu trúc dữ liệu và giải thuật bằng ví dụ rõ ràng, code C++/Python và animation trực quan ở các bài phù hợp.

## Trạng thái Phase 1

Trang này hiện là khung course. Nội dung bài học chi tiết sẽ được triển khai ở các phase sau.

## Chủ đề dự kiến

- Array
- Linear Search
- Binary Search
- Stack
- Queue
- Sorting
- Recursion
- Tree và Graph
