# Interview Prep

Interview Prep sẽ gom các pattern, bài tập và checklist ôn tập cho phỏng vấn kỹ thuật.

## Trạng thái Phase 1

Trang này là khung course. Nội dung chi tiết sẽ được triển khai sau MVP học tập.

## Chủ đề dự kiến

- Array patterns
- Two pointers
- Sliding window
- Stack patterns
- Tree traversal
- Graph BFS/DFS
