# C++

Course C++ sẽ giúp người học nắm cú pháp, kiểu dữ liệu, hàm, cấu trúc điều khiển và các kỹ năng cần thiết để học DSA.

## Trạng thái Phase 1

Trang này là khung course. Nội dung chi tiết sẽ được viết sau khi thống nhất lesson template.

## Chủ đề dự kiến

- Cú pháp cơ bản
- Kiểu dữ liệu
- Điều kiện và vòng lặp
- Hàm
- Mảng và chuỗi
- Struct, pointer và reference
